### Concrete generic architecture

Implement a bounded compiled getter/paired-text resolver, not a new unconditional `recordSize == 36` ABI. Derive core stride, field offset/element width/slot count, preserved getter return, name multiplier and pointer-index width from register-consistent native instructions and a bounded reachable getter. Require the selected core root/extent to agree, complete per-root name/description consumer evidence without conflicting geometry, and a unique independently compiled aligned name boundary. Retain rejection/budget/cancellation as explicit outcomes; no address, title, hash, public count or label profile enters production.

Carry the proved scalar species-slot and paired-description binding immutably with the selected typed ability-name layout. Supply the existing `AbilityNameResolver` direct-compiled tier before legacy shape alternatives and reuse `AbilityDescriptionResolver`/`AbilityDescriptionCodec` for the owned pointer layout. Catalog species joins must read the proved binding, not the legacy record-size overload; description materialization must use the selected typed result rather than re-rank unrelated pointers. Preserve the legacy route for independently supported existing ABIs and existing locale/storage/API behavior. The compiled text binding grants no automatic ability-mechanics authority.

Focused changes are `parse/CompiledAbilityTextResolver.kt` plus bounded getter/accessor helpers, immutable models and a compiled terminated-inline-array mode in `dataset/abilities/AbilityModels.kt`/`AbilityNameCodec.kt`, direct typed selection in `family/CompiledAbilitySemanticResolver.kt`/`SemanticDomainStrategy.kt`, stride handling in `parse/FamilyProbeEvidence.kt`, and proved-binding reads in `catalog/RecordMaterializers.kt`/`AbilityDescriptionMaterializer.kt`, with synthetic resolver/materializer/integration controls. Reuse the existing GF header layouts through a narrowly scoped `GbaPublishedHeaderResolver.kt` role-triple helper anchored to the independently selected core: header words nominate roles, never replace compiled ownership. Explicitly isolate this text binding from automatic mechanics publication in the existing aggregation/materializer paths. Add fields to an existing broader model only if integration genuinely requires them; do not introduce an unconditional 36-byte table profile or unrelated refactor.

For the proved inline array, each cell must contain its native terminator, and its independently owned direct extent must not be trimmed into a legacy post-sentinel alias interpretation or extended into the following object. Existing fixed-width/alias ABIs retain their current behavior. Bind both the selected core's logical record size and physical stride, and require the complete core extent rather than only the ability field. Getter counter loops may be unrolled into distinct abstract states; any reachable cycle without proved termination rejects the contract. Reject empty/unpredictable stack register lists, writes through SP beyond allocated locals, unsupported SP/PC changes, unrestored live LR after calls, unaligned typed summary inputs and signed comparisons outside the interpreter's proved nonnegative domain. Accessor call preservation follows the ARM callee-saved-register convention; this is a bounded local consumer proof, not whole-program callee analysis. Description rows still pass the existing prose codec independently: malformed rows and explicit missing-prose tokens cannot erase valid later rows, redirect selection to another pointer table, or fabricate natural prose. Preserve the native token in immutable typed evidence rather than counting it as decoded prose.

## Architecture decision gate

If the actual compiled ABI is different, update the concrete architecture with the evidence while preserving every requirement above; do not invent authority or silently shrink acceptance.
