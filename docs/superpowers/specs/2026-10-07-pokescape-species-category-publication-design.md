## Established cause and authority boundary

The selected description codec already returns a native category in `DescriptionRowOutcome.Decoded`; `ResolvedDescriptionLayout.catalogDescriptions()` preserves it in `DescriptionRecord.category`. Catalog media materialization joins those description rows to native species/forms for prose and dimensions but never copies the category. `SpeciesRecord`, the language overlay and selected-language projection have no species-category field/map; the companion species API has no category field. Thus the loss is publication/persistence, not a missing native table or a reason to change the accepted description resolver.

Prior independently accepted Dex evidence checks 906 physical category prefixes and the compiled native row aliases used for 1,235 published species/form descriptions. This is retained evidence, not a new original-read permission or completed category publication. A fresh exact-source parser and separately reviewed independent verifier must check every newly published category/native alias before acceptance.

## Architecture

A small category materializer projects strictly validated selected physical rows once, under cancellation/extent/work limits. For FF-terminated western inline rows it rechecks the bounded native cell without changing the existing prose codec thresholds; for the 28-byte Japanese ABI it reuses the existing strict six-byte zero-terminated glyph helper. It requires agreement with the selected decoded row's category. This avoids promoting merely plausible legacy category decoding or reading beyond a category cell.

Catalog media materialization applies this physical-row category map using its existing description-key/applicability decision. Locale extraction moves only available categories into a language overlay, leaving a structural core marker. Overlay coverage is based on the actual applicable species/form IDs; category absence does not demote the accepted prose/dimension capability. Runtime projection and the optional companion API value read the selected overlay only. Non-authorized description routes may remain category-unavailable and do not become unjustified N/A.

Storage and digest codecs include the explicit field/map/capability with existing size/reference bounds. The overlay DTO requires a non-null `speciesCategories` map and rejects null values; its constructor enforces available/nonblank values, immutable snapshots and coverage. Keys and expected totals use positive species IDs with applicable Dex/description/category markers, never physical row count. Core category markers retain applicability but no text. Gson's direct species decode must reject a missing/null new field rather than bypass Kotlin defaults. Canonical digest automatically includes the persisted field/map; ordering and other sequences remain unchanged.

The emitted overlay payload format advances from 1 to 2 and parser revision from 91 to 92; SQL remains 2. Existing positive caller-defined overlay versions remain supported as projection identities, not retroactively interpreted as universal schema numbers. Reader metadata rejects any prior parser revision before section decoding; no category migration/fabrication. Category capability uses actual strict category fields independently of prose coverage. `speciesCategory(id)` reads only the selected overlay, including UNKNOWN-language catalogs; it never falls back to shared text. New category obligations in other retained ROMs are not declared solved or promoted without their own acceptance.

Generated-only reconciliation verified retained row/binding hashes, 906 physical rows, all 905 positive rows reached by 1,235 compiled aliases, and the prior independent verifier's 906 raw category-prefix checks. No original or production parser was opened/executed. This establishes reuse prerequisites only; fresh publication acceptance remains mandatory.
