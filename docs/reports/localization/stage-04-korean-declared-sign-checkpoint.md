## Static authority contract

The output is the headline of a sign command's declared ROM text operand. It is not a guarantee of the text displayed by arbitrary live execution. Full graphics/font descendant noninterference is outside this static contract; unexamined descendants supply no return or preservation evidence.

The compiled binder connects the accepted map descriptor to its selected map-group row, attribute/event readers, five-byte background record and kind-0 script path. The bound dispatcher selects the exact little-endian operand reader, bank/address storage and direct-text template. The selected repeat-text consumer references that same storage and connects it to the text dispatcher, START handler and token-aware LINE/DONE grammar. Supported setup-wrapper structure is constrained without interpreting the graphics engine. Direct interpretation-path calls require structural evidence; arbitrary CALL operands and source labels are not authority.

Addresses and state references are related structurally and support relocation. Production does not select by ROM title, filename, hash, language identity or fixed evidence addresses. Pinned public source is an independent structural/text oracle only. The final selected-root linkage required a bounded adjacent-loader investigation, not a whole-ROM locator expansion.

Only the supported kind-0 direct declaration receives the compiled grammar. Explicit absent, incomplete, conflict and budget outcomes remain distinct. Selected incomplete/conflicting/exhausted evidence cannot retry a family opcode, while unrelated decoys cannot disable valid legacy parsing. Unknown or malformed sign text stays missing; independent numeric, item and destination POIs remain available.

## Text and cache behavior

Korean LINE and DONE are recognized at token boundaries under the proven consumer grammar, without redefining global codec terminators or applying Western substitution bytes indiscriminately. Reads are bounded by the selected bank, byte budget, structural objects and the next independently bound declared-text root in the map. A neighboring declaration supplies a boundary even when its text is malformed; identical roots remain legitimate aliases. A boundary splitting a multibyte token cannot be crossed to borrow a later record's terminator.
