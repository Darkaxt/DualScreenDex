# Stage 4 native compiled-type checkpoint

Status: **verified bounded native compiled types and integration; not Stage 4 closure**.

## Authority and scope

This bounded `LNG-D005` checkpoint extends the existing decoded complete-domain type resolver. Semantic roles come from exact, language-scoped compiled type labels, not presumed numeric order, header language, game title, ancestry, filename, or ROM hash. Reordered complete standard-label domains remain valid; missing, duplicate, custom, wrong-language, malformed, or ambiguous domains remain unavailable.

- Japanese and Korean labels extend the existing localized lexicon. Japanese STEEL/DARK/MYSTERY are `はがね` / `あく` / `？？？` (three U+FF1F characters); Korean FIRE is `화염`. No speculative ASCII/fullwidth aliases are added.
- Existing GB bank-local pointer-consumer validation is retained.
- Existing seven-byte GBA behavior is retained. Five-byte rows require concrete instruction-site evidence and a bounded adjacent Thumb sequence computing `type * 4 + type + tableRoot`.
- The five-byte check revalidates literal target/bounds and register flow. The shift must preserve the original type, and the root load must preserve the computed product. A readable table or unrelated literal reference does not prove this ABI.
- Complete-domain validation, unique-candidate rejection, token decoding, and cancellation remain required. No identity-specific offsets, codec/schema changes, or language-based width overrides are introduced.
