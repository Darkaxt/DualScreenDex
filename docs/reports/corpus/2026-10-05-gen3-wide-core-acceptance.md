## Generic authority and regression corrections

The resolver admits complete bounded name-copy, inverse-first-match/forward-map, default/variant type and six actual u16-stat consumers. Same-root bidirectional pairing precedes role cardinality: unrelated complete conversions do not compete, while two complete pairs or conflicting form roots remain rejected. The name and map bounds agree, including their separate reserved slots. Native IDs are never assumed to equal Dex numbers.

The default 64-byte stat ABI is interpreted only by the typed stat codec. Four-byte ordinary level-up records require u16 move/level fields, unshifted level comparisons, explicit termination and coherent move prerequisites. Independently compiled 20-byte and 56-byte aligned byte-target move prefixes remain distinct from the existing hybrid 20-byte ABI. The 56-byte extension is not interpreted as mechanics. Maximum acquisition references establish a safe ordinary minimum, not the full game move bound.

A production checkpoint exposed a second boundary error: sprite validation divided valid streams by all 2,301 physical slots, rejecting the table before canonical materialization. The correction checks the full pointer span but validates and renders only independently proven canonical native slots, retaining native palette indexing and the existing **90%** threshold. Aliases, holes and reserved rows cannot fill coverage. Synthetic tests verify palette pixels, missing/mismatched authority, malformed domains and cancellation; final originals verify 1,025 actual rendered catalog sprites each. No live visual or exact-color acceptance is implied.

No project title, original hash, fixed original root, source cardinality, name-prefix heuristic or relaxed family threshold was introduced into production resolution. Public source is a structural oracle, not exact-build authority.
