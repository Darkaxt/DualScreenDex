# Pokémon ROM Hacks — Source Code Repositories

A mapping of each ROM hack archive in `D:\Temp\PokemonHacks` to the **public GitHub source repository** used to build it, where one exists (265 archives total).

## How to read this

- **GitHub Link** = the actual source code repo (usually a fork of a `pret` decompilation: `pokeemerald` / `pokefirered` / `pokeruby` for GBA, `pokered` for GB, `pokecrystal` / `pokegold` / `poketcg` / `pokepinball` for GBC).
- **`None found (closed-source/binary)`** = the hack is distributed only as an IPS/UPS/BPS patch, or its source is private/paid. Many classic hacks were made with binary tools (AdvanceMap / XSE / hex) and have **no source at all**. A handful of newer decomp-based hacks also keep their source private.
- A few entries link a **community port / bugfix fork** or an **engine-only** repo where the author never released the full hack source — these are annotated.
- A handful of zip files are variant builds (patch variants, Saiph 2 modes, SWSH patches) that all share one underlying repo — noted where relevant.

> **Caveat:** "None found" reflects what was discoverable via web search at 2026-08-14. A small number of these closed-source hacks may have since published source; if a favorite is marked closed, check the author's GitHub/Discord directly.
